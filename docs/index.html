Developer Reference

API Specifications

ฟังก์ชันมาตรฐานที่ Export ออกมาจากรากแพ็กเกจ @intech-software/chronera

Core Dates & Instants

localDate(year, month, day)

สร้าง Calendar Date แบบ Immutable ไม่บิดเบือนตาม Timezone ท้องถิ่น

instant(epochMilliseconds?)

สร้างจุดเวลาที่แน่นอนบนเส้นเวลาสากล (UTC)

startOfDay(date) / endOfDay(date)

คำนวณขอบเขตของวัน ณ เวลา 00:00:00.000 หรือ 23:59:59.999

Business Days & SLA

addBusinessDays(date, days, options?)

เพิ่มวันทำการโดยข้ามวันเสาร์-อาทิตย์ และวันหยุดนักขัตฤกษ์ประจำประเทศ

subBusinessDays(date, days, options?)

ลบวันทำการย้อนหลังข้ามปฏิทินวันหยุด

isBusinessDay(date, options?)

ตรวจสอบว่าวันที่ระบุเป็นวันทำการหรือไม่

Calendar Conversions

convertCalendarDate(date, targetCalendar)

แปลงวันที่เป็น buddhist, japanese, roc, islamic-civil, persian หรือ indian

formatDate(date, options)

จัดรูปแบบวันที่ตามมาตรฐานทางการของแต่ละวัฒนธรรม

TimeZone Operations

formatInTimeZone(date, timeZone, pattern)

จัดรูปแบบวันที่และเวลาใน IANA TimeZone ที่กำหนด

getTimeZoneOffset(timeZone, date, format)

ดึงค่า UTC offset เป็นสตริง (+07:00) หรือ Object
