Engine Architecture

Built for Precision, Ergonomics, and Global Compliance

Designed to solve the real-world complexity of multi-cultural calendars, timezones, and SLA calculations without third-party baggage.

7 Non-Gregorian Calendars

Convert bi-directionally between ISO 8601 Gregorian, Thai Buddhist (พ.ศ.), Japanese Era (令和/平成), Taiwan Minguo (民國), Islamic Hijri, Persian Solar Hijri, and Indian Saka.

Enterprise SLA Engine

Calculate legal due dates, shipping deadlines, and banking settlement days with deterministic weekend skipping and automatic public holiday roll-over observation.

100% Zero Dependencies

Built natively on standard ECMAScript and Intl specifications. Zero external npm packages, zero security supply-chain vulnerabilities, and minimal bundle footprint.

Developer Reference

API Specifications

Standard functions exported directly from the primary root package @intech-software/chronera.

Core Dates & Instants

localDate(year, month, day)

Creates an immutable calendar date object without timezone distortion.

instant(epochMilliseconds?)

Creates an exact point in universal timeline (UTC).

startOfDay(date) / endOfDay(date)

Calculates boundaries of a calendar day at 00:00:00.000 or 23:59:59.999.

Business Days & SLA

addBusinessDays(date, days, options?)

Adds working days skipping weekends and country statutory holidays.

subBusinessDays(date, days, options?)

Subtracts working days backwards across statutory calendars.

isBusinessDay(date, options?)

Returns boolean indicating whether date is an active working day.

Calendar Conversions

convertCalendarDate(date, targetCalendar)

Converts date to "buddhist", "japanese", "roc", "islamic-civil", "persian", or "indian".

formatDate(date, options)

Formats date using standard legal locale patterns (dateStyle, timeStyle).

TimeZone Operations

formatInTimeZone(date, timeZone, pattern)

Formats instant or date string in any valid IANA timezone.

getTimeZoneOffset(timeZone, date, format)

Extracts exact UTC offset string ("+07:00") or structured object.
