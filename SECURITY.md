# Security Policy

## Supported Versions

Only the latest release is actively supported with security patches.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability

Please use GitHub Private Vulnerability Reporting to report security issues.
Alternatively, contact the security team:

```text
security contact to be defined by the Intech organization
```

Please include:

- Affected Chronera version;
- Environment (Node.js version, browser, OS);
- Impact analysis;
- Reproduction steps or proof of concept;
- Proposed mitigation if available.

Reports will be acknowledged promptly and investigated in private before public disclosure.
